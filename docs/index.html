What the model is learning from

Factor rankings appear after the first model beats the “same as now” baseline on unseen time.

Minutes are posted waits, not stopwatch waits. Ranges, when shown, are the model’s 10th–90th percentile. Model selection uses the newest 20% of time, with a forecast-horizon gap before training ends. This is preliminary backtesting, not independent prospective validation. MAE is average absolute error, not a confidence interval. MAPE counts only rides whose true wait was 20+ min — percentages on a 5-min wait are noise. Queue scenarios = posted wait × assumed hourly capacity × standby share. These are uncalibrated ranges, not measured headcounts or park attendance. Edit capacity.json to tune them. Historical change-log replay is identified separately from live samples.
